# 우성하이텍 제품 카탈로그 (웹)

시설원예 자동화 제품 카탈로그. 정적 사이트라 **GitHub Pages에 그대로 올리면 동작**합니다.

## 구조

```
web/
├── index.html          전체 제품 보기 (10개 카테고리 → 제품 → 상세 팝업)
├── rollupstar.html     롤업스타 전동개폐기 카탈로그 (10모델)
├── rollupmaster.html   롤업마스터 컨트롤 박스 카탈로그 (10시리즈)
└── assets/
    ├── css/  base.css · app.css · catalog.css
    ├── js/   data.js   ← 모든 제품 데이터 (3페이지 공유)
    └── img/  45장 (약 0.9MB, 최적화 완료)
```

**총 용량 약 1.1MB** — 저장소·대역폭 부담 없음.

## 배포 (GitHub Pages)

```bash
git init
git add .
git commit -m "제품 카탈로그 초기 배포"
git branch -M main
git remote add origin <저장소 주소>
git push -u origin main
```

저장소 **Settings → Pages → Source: main / (root)** 선택 후 저장하면
`https://<계정>.github.io/<저장소>/` 로 공개됩니다.

> `web/` 폴더 안의 파일들이 저장소 **최상위**에 오도록 올리는 것이 가장 간단합니다.
> (또는 저장소 루트에 두고 Pages 소스를 `/web`으로 지정)

## 페이지 간 이동

- `index.html` 제품 팝업의 **"카탈로그에서 보기"** → 해당 카탈로그로 이동
- 링크에 모델이 해시로 전달됨 → `rollupstar.html#WSM-6035` 처럼 열면 **그 모델이 자동 선택**
- 각 카탈로그 상단 **"← 전체 제품보기"** 로 복귀

## 데이터 수정 방법

제품 정보는 전부 `assets/js/data.js` 한 곳에 있습니다.

| 상수 | 내용 |
|---|---|
| `OPENERS` | 전동개폐기 10모델 (토크·감속비·리미트·무게 등) |
| `CTRLS` | 컨트롤러 10시리즈 (모델표·설정값·기능) |
| `CATS` | 카테고리 10개와 그 안의 제품 카드 |

수치만 고칠 때는 이 파일만 수정하면 3개 페이지에 모두 반영됩니다.

## 출처 · 주의

- 제원은 **제조사 사용설명서(정본)** 기준입니다.
- 홈페이지 값과 다른 항목이 일부 있습니다 → `../제품데이터/_확인필요_불일치.md` 참조
  - 예) WSM-2475H: 설명서 6/9 kg·m vs 홈페이지 7/10 kg·m (현재 **설명서 값** 사용)
- 아직 사진이 없는 품목: 커튼제어 10종, BF-2001, WTVC·WTDC
- 준비중 카테고리 6개(순환팬·양액·토양·스마트팜·ICT·수경재배)

## 오프라인(전시용) 버전

인터넷 없이 쓰는 단일 파일 버전은 `../전시용/` 에 있습니다.
이미지가 파일 안에 내장되어 있어 **HTML 하나만 복사해도** 동작하지만 용량이 큽니다(각 0.5~1MB).
전시회 노트북·키오스크용으로 사용하세요.
