RVC란?

2개 채널을 서로 다른 조건으로 독립 운전하는 5인치 TFT 환경제어 컨트롤러입니다.

각 채널마다 온도제어 또는 시간제어를 선택할 수 있습니다.

RVC시리즈

5인치 컬러 TFT에서 두 채널의 현재상태를 동시에 확인하고, 채널마다 온도 또는 시간 운전을 독립적으로 선택하는 환경제어 컨트롤러입니다.

채널 2채널 독립화면 5인치 TFT제어 채널별 온도·시간 선택출력 DC24V1채널과 2채널은 서로 다른 운전조건을 사용할 수 있으며, 같은 채널에 속한 출력 라인들은 동일한 조건으로 함께 작동합니다.

RVC의 선택 기준

서로 다른 두 구역을 각각 온도 또는 시간 조건으로 독립 관리해야 하는 시설에 적합합니다.

2채널과 연결 대수

2채널은 두 개의 독립 제어구역이라는 의미입니다. 모델별 전체 출력 라인은 1채널과 2채널에 절반씩 배분됩니다.

2-CHANNEL CONTROL각 채널의 제어 방식을 독립 선택＋
1채널온도제어 또는 시간제어

1채널의 5단 변온·열림률·시간조건을 별도로 설정합니다.

2채널온도제어 또는 시간제어

2채널도 1채널과 관계없이 자체 제어 방식과 설정값을 사용합니다.

예를 들어 1채널은 온도제어, 2채널은 시간제어로 운전할 수 있으며 두 채널 모두 온도 또는 모두 시간으로 설정할 수도 있습니다.

개별 스위치각 라인 열림·정지·닫힘

각 채널은 선택한 조건으로 독립 자동운전합니다. 개별 스위치를 중앙의 정지 위치에 두면 해당 라인은 자동운전에서 제외되며, 수동운전에서는 각 라인을 직접 조작할 수 있습니다.

1채널과 2채널의 현재상태와 주요 설정값을 한 화면에서 비교하고, 각 채널 설정 화면에서 온도·시간 데이터를 독립적으로 변경합니다.
